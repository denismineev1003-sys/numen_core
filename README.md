# numen_core

Репозиторий проекта NUMEN — независимое хранилище узлов, дельт и методологии.

## Структура

- `node/` — выпуски узла NUMEN NODE (эталон: `numen_node_v6.3.html`, SHA-256 = d5562096affcf76cfd0358df6dcf6b9ddc43ca0638dacf872edefee2bf589d8a)
- `docs/` — методология и протоколы
- `deltas/` — дельты дня (по одной на такт)

## Правило трёх носителей

Выпуск считается состоявшимся, когда файл лежит минимум в трёх местах
и SHA-256 всех копий совпадает: GitHub + локальный диск + облако.

## Правила работы

1. Окно сессии — не хранилище. В окно проходит только дельта дня.
2. Артефакты (файлы, таблицы, скрипты) живут здесь; агенты читают их по raw-ссылкам.
3. Каждый такт начинается с чтения дельты, а не с пересказа истории.
